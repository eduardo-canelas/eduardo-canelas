## 🛠️ &nbsp; How I Work

```
1. Listen     →  understand the actual problem, not the requested feature
2. Sketch     →  data model + flow before pixels
3. Build      →  small, atomic, shippable increments
4. Iterate    →  measure, talk to users, throw away what doesn't earn its keep
```

Real love for the craft. I'd rather ship one thing that quietly changes how people work than ten things that look good in a screenshot.
